# bookkeeping-skills

Agent skills for freelancer bookkeeping (monthly close, subscription audit, accountant handoff), built on [ledger-mcp](https://github.com/folioflux/ledger-mcp).

> **Status:** In development - not ready for use yet.

## What it will do

bookkeeping-skills will be a set of agent skills for Claude Code, Cursor and Codex that guide an agent through common freelancer bookkeeping tasks, using ledger-mcp for the numbers:

- **Monthly close:** review a month of transactions, flag uncategorised items and summarise income and expenses.
- **Subscription audit:** find recurring charges and list what you are paying for.
- **Accountant handoff:** prepare a tidy summary, with the source rows behind each figure, to share with your accountant.
